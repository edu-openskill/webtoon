# 대사 편집 스킬

## 언제 사용

- 스토리·캐릭터·레이아웃이 다 나온 후 패널별 대사를 작성할 때
- 사용자가 "톤 바꿔줘", "더 캐주얼하게", "X 인물 대사만 다시" 요청한 경우
- 다른 에이전트로부터 "보이스 불일치", "글자 수 초과" 피드백을 받았을 때

## 핵심 원칙

### 1. 글자 수 통제
- 한국어 기준 말풍선당 20자 이내 권장
- 길면 2개 말풍선으로 분할 (한 인물이 연달아 말함)
- `panel-layout-planner`가 권장치를 줬으면 그것이 우선

### 2. 보이스 일관성
- `_workspace/character-bible.md`의 voice cue 준수 (어휘·어미·말 습관)
- voice cue가 없는 신규 인물 → 이번 화에서 추정한 보이스를 character-bible에 추가 제안

### 3. 리듬 설계
- 모든 패널에 대사가 들어갈 필요 없음 → **침묵 패널 보존**
- "짧다-짧다-길다", "침묵 → 폭발" 같은 리듬을 의도적으로 만들기
- 감정 절정 패널은 한 단어 또는 침묵이 더 강할 때가 많음

### 4. 설명을 대사에 넣지 않기
"우리가 어제 그 일을 겪었기 때문에..." 같은 회상 설명은 시각이나 내레이션으로. 대사는 **인물의 욕망·감정·반응**만.

### 5. 구어체
"그것은 ~이다", "~인 것이다" 같은 문어체 금지. 일상 구어체 — "그거 뭐냐", "야 미쳤어?", "...진짜로?"

**Why this matters:** 웹툰 독자는 빠르게 스크롤한다. 긴 대사는 건너뛰고, 문어체는 몰입을 깬다. 짧고 리듬 있는 구어가 캐릭터에 살을 붙인다.

## 작업 순서

### 1. 컨텍스트 로딩
4개 파일 모두 필수:
- `_workspace/episode-{NN}/01_story.md` — 씬 핵심 대사 의도
- `_workspace/episode-{NN}/02_character_prompts.md` — 등장 인물 목록
- `_workspace/episode-{NN}/03_panel_layout.md` — 패널별 자리·글자 수 권장치
- `_workspace/character-bible.md` — 인물 voice cue

### 2. 패널 1:1 매핑
레이아웃의 모든 패널 번호에 대해 대사 블록을 만든다. 패널 번호가 동일해야 시각 작업자가 헷갈리지 않음.

각 패널 블록:
- 내레이션이 있으면 `(내레이션): "..."`
- 인물 대사: `{인물명}: "..."` (글자수 메모 추가)
- 침묵 의도면 `(침묵 — 의도된 여백)`
- 효과음(텍스트로 들어가는 것)은 `효과음: 콰앙`

### 3. 셀프 검수
완성 후 한 번 더 훑으며:
- 같은 인물이 화 내내 보이스 일관성 유지하는가
- 글자 수 초과 패널 없는가 (있으면 분할 또는 레이아웃 확장 요청)
- 침묵 패널이 충분히 있는가 (모든 패널이 말풍선 가득이면 피로함)
- 문어체 표현 남아 있는가

### 4. 산출

`_workspace/episode-{NN}/04_dialogue.md`에 저장.

## 하지 말 것

- **스토리 사건 변경 금지** → 인물이 안 할 말을 하게 되면 `story-writer`에게 알리고 수정 요청
- **레이아웃 패널 번호 임의 변경 금지** → 패널 번호는 레이아웃이 소유
- **모든 패널을 대사로 채우기 금지** → 침묵은 디자인이다

## 후속 작업

- 부분 재작성 ("Page 3만") → 해당 페이지 블록만, 다른 페이지는 보존
