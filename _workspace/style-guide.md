# Webtoon Style Guide (Template)

> 이 파일은 시리즈의 톤·아트 스타일·페이싱 컨벤션을 정의한다. 모든 에이전트가 작업 전 가장 먼저 읽는다.
> **사용자가 시리즈 실제 값으로 채워야 한다.** 빈 칸은 합리적 기본값으로 진행됨.

## 시리즈 정체성

- **장르:** {예: 미스터리 / 로맨스 / 액션}
- **타깃 독자:** {예: 20~30대 여성, 10대 후반 등}
- **핵심 톤:** {예: 차분하고 음울, 밝고 발랄, 비장감}
- **금기 표현:** {예: 과한 욕설, 정치 풍자 등}

## 아트 스타일 (이미지 프롬프트용)

- **스타일 prefix:** `Korean webtoon style, cell-shaded, vivid color, soft lineart`
- **색감:** {예: high saturation / muted earth tones / pastel}
- **선화:** {예: clean thin lineart / rough sketch / bold ink}

## 페이싱 컨벤션

- **에피소드당 평균 페이지 수:** 22
- **에피소드당 평균 패널 수:** 60~70
- **씬당 페이지 수:** 1~3
- **침묵 패널 비율 목표:** 8~12%

## 인물 보이스 기본 룰

- 모든 인물은 자연스러운 구어체
- 문어체("~인 것이다") 금지
- 인물별 voice cue는 `character-bible.md`에 누적 관리

## 말풍선 컨벤션

- 한국어 기준 말풍선당 20자 이내 권장
- 한 인물이 연달아 말할 때 말풍선 2~3개로 분할
- 큰 외침/충격은 단어 1~2개 + 큰 폰트
