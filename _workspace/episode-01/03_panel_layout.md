# Episode 01 — Panel Layout

## Pacing Summary
- **총 페이지**: 22
- **총 패널**: 67
- **침묵 / 여백 패널**: 7개 (≈10.4%)
- **풀-블리드 큰 컷**: 3개 (Page 12 강민호 두번째 질문 / Page 13 회의실 freeze / Page 22 후크 마지막)

- 1~3 페이지 (도입): 잔잔한 톤, 패널당 충분한 여백
- 4~8 페이지 (시연 + 4인 반응): 빠른 톤, 패널 작게 여러 개
- 9~15 페이지 (강민호 침묵 + 두 질문): **천천히, 큰 컷, 침묵 다수** — 페이싱 변화로 무게 만듦
- 16~17 페이지 (회의 종료): 일상 톤, 어색함 짧게
- 18~22 페이지 (밤 + 후크): 어두운 톤, 점점 클로즈업, 마지막 풀-블리드로 절정
